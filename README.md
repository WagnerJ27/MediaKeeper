# MediaKeeper

MediaKeeper ist eine JavaFX-Anwendung zur Verwaltung von abgeschlossenen Filmen,
Serien, Büchern und Spielen.

## Funktionen

- Medien hinzufügen
- Medien anzeigen
- Medien löschen
- Speicherung der Einträge
- JavaFX-GUI
- CSS-basiertes Styling

## Technologien

- Java 
- JavaFX 
- Git / GitHub
